# LotLog Website

Marketing site for **LotLog**, nested under LogSuite:

`LogSuiteWebSite/lotlog/`

## Local preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open `http://localhost:8080/lotlog/`.
