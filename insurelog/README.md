# InsureLog website

Marketing site for **InsureLog** (independent insurance agent / needs & renewals).

## Preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open: `http://localhost:8080/insurelog/`

Live (GitHub Pages): https://abecheng.github.io/LogSuiteWebSite/insurelog/
