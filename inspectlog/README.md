# InspectLog Website

Marketing site for **InspectLog**, nested under LogSuite:

`LogSuiteWebSite/inspectlog/`

Solo / independent home inspectors — voice notes on-site → Property + Client → zone notes + repair $ → field work paper PDF.

## Local preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open `http://localhost:8080/inspectlog/`.
