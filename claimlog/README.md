# ClaimLog website

Marketing site for **ClaimLog** (independent adjuster / loss inspection).

## Preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open: `http://localhost:8080/claimlog/`

Live (GitHub Pages): https://abecheng.github.io/LogSuiteWebSite/claimlog/
