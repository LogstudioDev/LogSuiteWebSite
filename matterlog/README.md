# MatterLog Website

Marketing site for **MatterLog**, nested under LogSuite:

`LogSuiteWebSite/matterlog/`

## Local preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open `http://localhost:8080/matterlog/`.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Landing |
| `contact.html` | Contact |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Use |
