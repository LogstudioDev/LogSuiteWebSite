# RealtyLog Website

Marketing site for **RealtyLog**, nested under LogSuite:

`LogSuiteWebSite/realtylog/`

## Local preview

```bash
cd LogSuiteWebSite
python3 -m http.server 8080
```

Open `http://localhost:8080/realtylog/`.
